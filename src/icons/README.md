# Icons

One SVG per icon: 14×14 grid, `currentColor`, round caps, `stroke-width` 1.4. The stroke scales with the icon. The only exception is `more`: its dots use 2.5. Import what the page needs in `src/icons.ts`, so unused icons stay out of the bundle.

## License

Icons marked `Streamline` or `changed` come from [Streamline](https://www.streamlinehq.com/), Flex free set, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source: [`@iconify-json/streamline-flex`](https://www.npmjs.com/package/@iconify-json/streamline-flex) 1.2.3. All of them were changed in one way: the stroke went from 1 to 1.4 to match the set's published artwork. The menu links to `/credits.html`, which names the author, the license and the changes.

Icons marked `drawn` are ours, drawn in the same style. Most reuse a detail of a Flex icon, so treat them under the same license.
