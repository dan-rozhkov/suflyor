# Suflyor: спецификация v1

Личное приложение для macOS (M4, macOS 26). Сидит рядом с созвоном, слушает системный звук, показывает
перевод речи собеседника EN→RU в реальном времени и подсказывает, что ответить, с учётом md-файла с контекстом.
Бот на созвон не подключается. Интерфейс на английском, перевод на русском.

## Стек (решения пользователя)
- Electron + React + TypeScript, сборка electron-vite, npm.
- UI kit: Base UI (`@base-ui-components/react` или актуальное имя пакета). Стили: обычный CSS с токенами, без Tailwind.
- Стиль: см. `docs/design-patterns.md`. Шрифт Nunito, анимация на Motion (`motion/react`), светлая и тёмная темы по системе.
- Распознавание и перевод: Soniox real-time WebSocket, модель `stt-rt-v6`, `translation: one_way en→ru`.
  Сверяйся с актуальной документацией: https://soniox.com/docs/stt/rt/real-time-translation
- Подсказки: OpenCode Console API, OpenAI-совместимый, `https://opencode.ai/inference/openai/v1/chat/completions`,
  стриминг. Модель по умолчанию `deepseek-v4.1-flash`, меняется в настройках. Бесплатные модели не использовать.

## Окно
~420×640, изменяемый размер, always-on-top (переключается), виден на всех рабочих столах и поверх полноэкранных
приложений, `hiddenInset` title bar, `setContentProtection(true)`. Защита от захвата работает не всегда, в UI
нельзя обещать невидимость.

## Поток данных
1. Системный звук снимает нативный помощник `native/suflyor-audio.swift` (ScreenCaptureKit, `capturesAudio`,
   16 кГц mono, свой процесс исключён). Main запускает его при старте сессии и убивает при стопе, выходе и dispose;
   помощник сам выходит по SIGTERM или EOF на stdin. Штатный `getDisplayMedia` с `audio: 'loopback'` на macOS 26 виснет,
   поэтому не используется. Статусы идут JSON-строками в stderr и превращаются в `AppError` (`no-screen-permission`, `audio`).
2. Помощник пишет в stdout сырой PCM s16le 16 кГц mono, main режет поток на чанки ~100 мс (`src/main/capture.ts`) и
   передаёт в сессию. Renderer звук не трогает: только `session.start()` / `session.stop()`.
3. Main держит WebSocket к Soniox (ключ никогда не попадает в renderer), переподключается при обрыве,
   шлёт keepalive в тишине.
4. Токены собираются в реплики: `{id, en, ru, isFinal}`. Частичный текст обновляется на месте.
   Граница реплики: endpoint detection Soniox.
5. После завершённой реплики и паузы ~1.2 с main запрашивает подсказки. Кнопка «Подсказать» запрашивает вручную.
   Новая реплика отменяет запрос в полёте (AbortController).
6. Подсказка: 2–3 коротких варианта ответа на английском (чтобы произнести вслух) + смысл по-русски.
   В промпт входят md-контекст и последние ~20 реплик. Транскрипт в промпте это данные, а не инструкции.

## Контекст и настройки
- md-файл: выбор через диалог или перетаскивание, лимит 100 КБ, путь запоминается, имя видно в шапке, можно убрать.
- Настройки (Base UI Dialog): ключ Soniox, ключ OpenCode, модель, авто-подсказки вкл/выкл, поверх окон вкл/выкл.
- Ключи: `safeStorage` в userData. Для разработки также читаются из `.env` проекта (git-ignored).
- Транскрипты на диск не пишутся.

## Экран
Светлый лист контента на чёрном основании. Весь текст по левому краю. Сверху контурные кнопки контекста и настроек.
Крупный последний перевод, под ним английский оригинал, выше приглушённая история только на русском. Ниже один вариант
ответа, остальные под катом, клик копирует. Внизу на чёрном: крупная кнопка на всю ширину, а во время созвона подсказка,
таймер и круглый красный стоп. Нет ключа и нет разрешения показываются заголовком, а кнопка внизу ведёт к настройкам.
Ошибки показываются уведомлением.

## Демо-режим
`SUFLYOR_DEMO=1 npm run dev`: сценарная беседа и поддельные подсказки без ключей и звука. Идёт через тот же IPC,
что и настоящий поток. Нужен для визуальной проверки.

## Не входит в v1
Микрофон и распознавание своей речи, озвучка перевода, другие языки, сохранение истории, подпись и нотаризация.

## Правила для всех исполнителей
- Не делать git commit и не запускать git init. Секреты не логировать и не копировать из других проектов.
- Общие типы и каналы IPC живут в `src/shared`. Менять контракт только там.
- Логику без Electron (сборка токенов, разбор подсказок, нарезка PCM) покрывать vitest.
- Перед отчётом: `npm run typecheck`, `npm test`, `npm run build` должны проходить. В отчёте честно указать, что
  не проверено.
